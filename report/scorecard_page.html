Every method, 2024

Equal weight: plain average of the core alphas. IC-weighted: alphas that predicted better over the past 12 months get more weight. Ridge: regression weights with a penalty against wild weights, on the core list or the broad list. Trees: boosted decision trees on the broad list. Buffer: the best blend, but a coin stays held until it leaves the top or bottom 30%, which trades less. To pass, a method needs a higher Sharpe than both benchmarks. "vs equal t" says how sure we can be that it beat the plain average day by day (2 or more is fairly sure).

Two fake alphas are scored with the same code on every run. If the random one scored well, or the one that cheats did not, the scoring would be broken.
